## 投資論點（One-Liner）

信驊以 70%+ 全球市占主導 server BMC（Baseboard Management Controller）標準晶片市場，AI server 出貨潮為其結構性正向 driver — 不僅出貨量受 AI server 滲透率推升，AST2700 系列 ASP 較前代上修，且 AI 機種 BMC 內容價值（function richness）擴大。fabless、零重資本、自然 USD hedge、高毛利（歷史 60%+）+ 高配息（80%+ 配息率）構成防禦+成長混合特性。中期 multi-bagger 需要 hyperscaler 自研 BMC 替代不擴大、AST2700 平順導入、以及非 BMC ASIC 業務（custom silicon for AI/networking）擴大。

## 三件值得買的理由

1. **BMC 結構寡占 + AI 量價齊揚**　每台 AI server BMC 滲透 100%、ASP 上修。下世代 AST2700 切入更先進製程，function set 涵蓋 AI 帶外管理（OOB）、root-of-trust、telemetry，ASP 較 AST2600 預期上修中個位數至雙位數百分比。
2. **財務體質：少見的「成長股 + 高息防禦」雙特性**　歷史毛利率 60%+、營業利益率 50%+、ROE 30%+、淨現金（無息負債）、配息率 80%+。fabless 模型 capex/sales 個位數，FCF/淨利接近 1。
3. **路徑外 optionality**：客製 ASIC 業務（Hyperscaler / AI 網通客戶）、車用／工控管理 IC、Edge AI controller 提供超出 BMC TAM 的成長拉力。

## 三件需要警覺的風險

1. **Hyperscaler 自研 BMC 加速**　AWS、Google、Meta、Microsoft 任一陣營若大規模轉自研，將直接侵蝕信驊高 ASP 段業務。是 the single biggest tail risk。
2. **客戶集中度**　前五大客戶佔比歷史 ⚠️ ~50-60%（待年報核對），任一 OEM platform refresh 延遲可造成季度級營收波動。
3. **中國國產 BMC 替代**　地緣政治＋「資訊技術應用創新」（信創）政策推動瀾起、ZTE Microelectronics 等替代方案；中國市場成長性受壓。
4. **估值風險**　TPEx IC 設計龍頭高 P/E 區間運行；若 AI server 出貨展望下修，multiple compression 加上 EPS 下修為雙殺。
